# 稍后观看助手

自动将关注的 B站 UP主发布的新视频添加到「稍后观看」列表的 Chrome 扩展。

**插件当前版本：2.0.0** · [下载插件](https://github.com/bailishta/bilibili-auto-watch-later/releases/download/v2.0.0/bilibili-auto-watch-later-v2.0.0.zip) · [更新日志](CHANGELOG.md) · [开发与发布](docs/DEVELOPMENT.md)

2.0.0 仅更新浏览器插件；Android 客户端继续使用 [v1.4.0 中的 APK](https://github.com/bailishta/bilibili-auto-watch-later/releases/tag/v1.4.0)。

## 功能

- **自动检查新视频** — 定时扫描追踪名单中 UP主的最新视频，自动添加到稍后观看
- **一键导入关注** — 首次使用时一键导入 B站关注列表中的所有 UP主
- **手动管理名单** — 支持手动添加/移除 UP主，灵活控制追踪范围
- **观看历史过滤** — 自动跳过已经观看过的视频，避免重复添加
- **可配置时间窗口** — 支持设定「多久以内的视频算新视频」（Chrome 扩展为 12 小时～7 天）
- **多个自动检查器（Chrome）** — 每个检查器独立设置名称、启停、每周各天时间、新视频范围，以及全部或指定 UP 主；同一时刻触发会排队执行
- **名单导入/导出** — 追踪名单可导出为 JSON 文件，支持在 Chrome 扩展与 Android 客户端之间互通
- **名单排序（Chrome）** — 按粉丝数、最近视频发布时间排序，每次检查自动更新并持久化数据，切换排序无需联网
- **配置备份（Chrome）** — 导出 JSON 备份，包含独立检查器、手动检查范围、排序、记录保留周数和追踪名单（含已采集记录）；导入前显示概览，确认后替换配置并重建排程，不包含登录信息
- **更新分布（Chrome）** — 按自然周显示每天更新的 UP 主人数，点击某天进入无指针的 12 小时表盘，通过上午／下午切换查看全天。表盘按实际时间标记更新位置，下方直接列出精确到分钟的时间、人数与 UP 主头像、名字，无需再次展开，可切换本周与往周

## 安装

### Chrome 扩展

1. 下载 [v2.0.0 Release](https://github.com/bailishta/bilibili-auto-watch-later/releases/tag/v2.0.0) 中的 `bilibili-auto-watch-later-v2.0.0.zip` 并解压（不要选择 GitHub 自动生成的 Source code）
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角**「开发者模式」**
4. 点击**「加载已解压的扩展程序」**，选择解压后的文件夹
5. 安装完成后会自动打开引导页，可一键导入 B站关注列表

### Android 客户端

1. 下载 [v1.4.0 Release](https://github.com/bailishta/bilibili-auto-watch-later/releases/tag/v1.4.0) 中的 APK 文件；插件 2.0.0 不提供新版 APK
2. 安装到手机，首次打开需通过内嵌 WebView 登录 B站
3. 登录后点击「导入关注列表」一键导入 B站 关注
4. 点击「立即检查」手动扫描新视频

## 使用说明

已有用户更新时，退出正在运行的检查，将新版解压到原扩展目录，然后在 `chrome://extensions/` 点击扩展卡片的重新加载并刷新管理页。沿用原扩展目录和安装项，避免卸载导致本地数据丢失；升级后旧排程会自动迁移。后续可通过「配置备份」保存和恢复配置。

- 点击扩展图标打开弹窗，可查看状态、手动触发检查
- 点击弹窗底部的「详细管理」按钮，在独立标签页打开管理中心
- 弹窗与管理中心均跟随系统自动切换浅色/深色模式
- 在管理中心添加/移除追踪的 UP主（支持 UID 或主页链接），搜索、排序及导入/导出名单
- 「手动检查范围」用于弹窗和管理中心的立即检查。在左侧「自动检查器」添加或编辑独立排程，选择全部或指定 UP 主；原有排程会自动迁移为「默认检查器」。删除所有检查器后自动检查保持关闭
- 导入名单后，下一次自动检查或点击「立即检查」会补全粉丝数、最近视频发布时间和已采集的更新记录；之后切换排序、重新打开管理页均使用已保存的数据。接口失败时保留旧值，尚无数据的 UP主 排在最后。
- 「更新分布」支持收起，详细说明和保留周数位于折叠的「统计设置」中；切换整周／钟表及收起展开使用非线性动画，并尊重系统减少动态效果设置。按浏览器本地时区、周一到周日统计，每周、每天、半天和每分钟均分别按 UP 主去重。进入某天默认显示上午，可切换下午；无指针表盘保留 1–12 数字与刻度，精确到分钟的时间、人数、头像和名字在紧凑列表中直接展示，无需二次展开。切换星期与周数不访问 B站。可自定义保留最近 1～52 个自然周（含本周）的已采集记录，默认 3 周；缩短后立即清理范围外记录，延长后逐步积累，每位 UP 主最多 500 条，首次采集只含接口返回的最近视频（当前每次最多 10 条），不是完整历史。删除追踪 UP 主后其记录也不再计入面板
- 弹窗和管理页统一使用 B站网页的系统字体体系，Windows 优先微软雅黑，表单控件同步继承
- 左侧「配置备份」可导出或导入配置；这与名单导入／导出分开。导入会替换检查器、设置和名单，保留本机已处理视频记录和统计信息；检查或数据修改进行中时需等待结束再导入
- 点击「打开稍后观看」可跳转到 B站稍后观看列表

## 注意事项

- 需要登录 B站（确保浏览器中已登录 bilibili.com）
- 自动检查依赖 Chrome 后台定时器，如果长时间未打开 Chrome 可能会延迟
- 已观看的视频会被自动跳过，不会重复添加到稍后观看
- 仅支持 Chrome 浏览器（基于 Manifest V3）

## 项目结构

```
├── manifest.json          # Chrome 扩展配置
├── service-worker.js      # 后台服务（定时触发、消息路由）
├── content.js             # 内容脚本（B站页面代理请求）
├── core/
│   ├── api.js             # B站 API 封装（WBI签名、Cookie、请求）
│   ├── checker.js         # 核心业务（扫描新视频、导入关注）
│   ├── meta.js            # 发布时间、粉丝数与更新记录采集
│   ├── activity.js        # 本地记录合并、自然周聚合与排序
│   ├── schedules.js       # 检查器验证、旧设置迁移和下次运行时间
│   ├── backup.js          # 配置备份格式验证与字段筛选
│   └── storage.js         # chrome.storage 封装
├── popup/                 # 精简弹窗：状态、统计、检查与快捷操作
├── manage/                # 独立管理页：名单、检查器、更新分布和导入导出
├── onboarding/            # 首次安装引导页
├── icons/                 # 扩展图标
├── ui/                    # 共享配色、字体与深色模式
├── tests/                 # 缓存与排程测试、浏览器和真实扩展测试
├── docs/                  # 开发说明与发布说明
├── CHANGELOG.md           # 插件更新日志
└── android-app/           # Android 客户端（Jetpack Compose）
```

纯 JavaScript + Manifest V3，无构建步骤，无外部依赖。
