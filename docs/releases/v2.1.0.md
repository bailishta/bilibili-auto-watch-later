## 浏览器插件 2.1.0

本次为次版本升级，继续使用 2.x 版本系列。Android 同步发布 [Android 2.1.0](https://github.com/bailishta/bilibili-auto-watch-later/releases/tag/android-v2.1.0)，安装包分别下载。

### 更新内容

- 按 B站账号保存已观看视频编号和观看时间，保留期内即使视频离开最近 500 条观看历史，也会跳过；接口失败时继续使用本地记录。
- 自动检查前提前两倍检查范围采集历史，采集间隔至少 12 小时、每个自然日最多两次；多个检查器、启动补采和手动检查共用持久化限额。
- 修正历史游标分页，增加重复游标退出保护；每页成功后立即保存，按检查范围保留完整自然日的数据。
- 更新应用图标、弹窗、管理中心及引导页样式，改进排序选择、检查器与设置交互。

### 下载与升级

下载附件 **`bilibili-auto-watch-later-v2.1.0.zip`**，解压后沿用原扩展目录替换文件，在 Chrome 扩展管理页点击重新加载，并刷新已打开的管理页面。不要卸载旧扩展，以保留本地配置。

首次安装需打开 `chrome://extensions/`，启用开发者模式并加载解压后的目录。GitHub 自动生成的 Source code 是仓库源码，请使用上述插件 ZIP。

观看历史首次同步最多读取最近 500 条；已超出此范围的旧历史无法补回。配置备份不包含登录 Cookie。
