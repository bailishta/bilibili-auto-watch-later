## 浏览器插件 2.0.0

本次仅更新 Chrome 插件，未发布 Android APK。

### 新功能

- **独立管理中心**：弹窗保留基础操作，完整管理在单独标签页打开，配色接近 B站，支持深色模式和窄屏。
- **多个自动检查器**：每个检查器独立设置名称、启停、星期时间、视频时间窗口及全部／指定 UP 主；同时触发会排队执行，旧排程自动迁移。
- **缓存排序**：粉丝数与最后视频发布时间随每次检查更新并持久化，切换排序不再重新获取数据，移除「刷新数据」按钮。
- **更新分布**：自然周统计、历史周切换，默认保留最近 3 周，可自定义 1–52 周。点击某天默认显示上午；无指针的 12 小时表盘搭配更新标记，紧凑列表直接显示具体分钟、人数、头像和名字，无需二次展开。
- **配置备份与导入**：JSON 备份检查器、设置、追踪名单和已采集记录，导入前校验与预览，恢复后重建排程。

### 修复与体验

- 修复自动检查器保存时无响应的问题，改善校验和错误反馈。
- 简化入口与统计面板文案，添加非线性动画并支持减少动态效果。
- 请求失败保留已有排序数据；保留追踪名单 JSON 导入／导出的兼容性。

### 下载与升级

下载下方 **`bilibili-auto-watch-later-v2.0.0.zip`** 并解压，ZIP 根目录包含 `manifest.json`。GitHub 自动生成的 Source code 不是插件安装包。

- 首次安装：打开 `chrome://extensions/`，启用开发者模式，选择「加载已解压的扩展程序」。
- 已有用户：等待检查结束，将文件更新到原扩展目录，重新加载扩展并刷新管理页；沿用原安装项以保留本地数据。
- 配置导入会替换检查器、设置和名单，保留本机已处理视频及统计；备份不含登录信息。
- 更新历史来自已采集的近期视频，并非完整投稿历史；每位 UP 主最多 500 条记录。
- Android 用户请继续下载 [v1.4.0 的 APK](https://github.com/bailishta/bilibili-auto-watch-later/releases/tag/v1.4.0)。
