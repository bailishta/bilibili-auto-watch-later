## Android 客户端 2.0.0

本次发布安卓 APP，要求 Android 8.0 及以上。浏览器插件继续使用 [插件 v2.0.0](https://github.com/bailishta/bilibili-auto-watch-later/releases/tag/v2.0.0)，两端安装包单独下载。

### 更新内容

- **手机界面**：首页、名单、更新、设置四个页面，B站风格配色、原生系统字体、非线性页面过渡，支持跟随系统／浅色／深色模式。
- **手动检查与缓存**：检查时统一采集粉丝数、最后视频发布时间和近期更新记录并持久化；移除独立刷新数据按钮，切换排序与更新面板无需联网。Android 不提供自动检查器、后台自动检查或排程。
- **名单管理**：紧凑头像行、名称与 UID 搜索、添加／删除、粉丝数与更新时间排序，保留 JSON 名单导入导出及插件互通。
- **更新分布**：按自然周查看每天更新的 UP 主人数，可切换本周及往周；某天默认显示上午，可切换下午。无指针 12 小时表盘搭配分钟刻度，列表直接显示具体分钟、人数、头像和名字。
- **记录保留**：默认最近 3 个自然周，可设置 1–52 周，每位 UP 主最多 500 条已采集记录；记录来自近期视频接口，不是完整投稿历史。
- **配置备份**：通过系统文件选择器导出／导入 JSON，导入前校验和预览；保存检查范围、排序、主题、保留周数、名单和已采集记录，不包含登录信息。可以读取插件备份的名单及支持的设置，忽略浏览器检查器。

### 修复

- 检查时间范围使用带下拉箭头、文字左对齐的选择框，菜单宽度与选择框一致，避免与「立即检查」按钮混淆。
- 「打开 B站 APP · 稍后再看」改为安卓客户端跳转，尝试独立页面、专用链接接收入口和新旧链接；增加安装查询及跳转日志。用户已确认旧版国内 B站 APP 可以正常跳转。
- 数据库通过显式迁移保留已有名单；页面切换和屏幕重建时保留检查状态。

### 下载与升级

下载下方 **`bilibili-watch-later-android-v2.0.0.apk`**。GitHub 自动生成的 Source code 是源码，不能作为 APP 安装包。

- APK 为 Release 构建，关闭调试模式并启用 R8 代码压缩；版本名 `2.0.0`、版本代码 `4`。
- 发布包沿用本机测试 APK 的签名证书，同签名安装项可以覆盖升级；如果旧安装项的签名不同，请先导出备份，再处理安装。
- 私钥及本机签名文件不上传。后续更新继续使用同一签名证书。
- 配置备份不包含登录 Cookie；Android 导出的配置不含浏览器排程，仅交换名单时建议使用名单导入／导出。
